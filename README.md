# Miramár Seacoast

A modern, responsive restaurant landing page for **Miramár Seacoast**, a seaside restaurant located in Ierissos, Halkidiki.

The website is designed to showcase the restaurant's atmosphere, story, gallery, contact information, and reservation options in a clean and elegant interface.

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- English and Greek language support
- Elegant restaurant-focused UI
- Hero section with call-to-action
- About / Our Story section
- Responsive image gallery
- Contact section with Google Maps integration
- Direct phone reservation links
- Instagram integration
- Responsive navigation with mobile hamburger menu
- Menu navigation prepared for the restaurant's QR menu
- Smooth scrolling
- Local SEO optimization

## 🛠️ Built With

- React
- JavaScript
- React Router
- Vite
- CSS
- Google Maps Embed
- Google Fonts
